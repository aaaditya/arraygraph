## What you will learn
- What a variable is, using labeled tiffin boxes.
- Common types: numbers, text, and true/false.
- How to swap two values without losing either one.

## The story
<Analogy emoji="🍱" title="Labeled tiffin boxes">
Your tiffin has small boxes. Each box has a **name sticker**.
One sticker says `roti`. Inside is bread.
One sticker says `sabzi`. Inside is vegetables.
You can open `roti` and put something new in. The old food is gone.
In code, a **variable** is that labeled box.
The **value** is what sits inside.
The **type** is the kind of thing inside — number, text, or yes/no.
</Analogy>

Without labels, you mix up boxes. Without types, you might try to "add" a name to a score by mistake.

## Now the code
Here is a tiny program that stores values and swaps two of them.

<CodeTabs
python={`# labeled boxes (variables)
a = 3
b = 7
name = "Riya"
ready = True          # boolean: yes/no

# swap a and b using a temp box
temp = a
a = b
b = temp

print(a, b, name, ready)  # 7 3 Riya True`}
javascript={`// labeled boxes (variables)
let a = 3;
let b = 7;
const name = "Riya";
let ready = true; // boolean: yes/no

// swap a and b using a temp box
const temp = a;
a = b;
b = temp;

console.log(a, b, name, ready); // 7 3 Riya true`}
java={`public class VariablesDemo {
    public static void main(String[] args) {
        int a = 3;
        int b = 7;
        String name = "Riya";
        boolean ready = true; // yes/no

        int temp = a;
        a = b;
        b = temp;

        System.out.println(a + " " + b + " " + name + " " + ready);
    }
}`}
cpp={`#include <iostream>
#include <string>

int main() {
    int a = 3;
    int b = 7;
    std::string name = "Riya";
    bool ready = true; // yes/no

    int temp = a;
    a = b;
    b = temp;

    std::cout << a << " " << b << " " << name << " " << ready << "\\n";
}`}
csharp={`using System;

class VariablesDemo
{
    static void Main()
    {
        int a = 3;
        int b = 7;
        string name = "Riya";
        bool ready = true; // yes/no

        int temp = a;
        a = b;
        b = temp;

        Console.WriteLine($"{a} {b} {name} {ready}");
    }
}`}
/>

Different languages spell types differently. The tiffin-box idea stays the same.

## Common mistakes
- Using a name before you put anything in the box.
- Mixing types carelessly, like adding a number to a name.
- Swapping with `a = b` and then `b = a` — both become the same value. You need temp.

## Interview angle
<InterviewTip>
Interviewers may ask: "What is a variable?" Keep it simple.
Say: "A named place in memory that holds a value."
Then mention type: number, string, or boolean.
If they ask about swap, show the temp-box steps out loud.
</InterviewTip>
