## What you will learn
- What coding means in plain words.
- Why every step must be clear and in order.
- How a short list of instructions becomes a tiny program.

## The story
<Analogy emoji="☕" title="A robot that makes chai">
Imagine a helpful robot in your kitchen.
You say "make chai". The robot freezes. It does not guess.
You must say each step: boil water, add tea, add milk, pour.
If you skip "boil water", you get cold brown water.
If you swap the order, you get a mess.
**Coding** is writing those exact steps so a computer can follow them.
</Analogy>

A computer is like that robot. It is fast, but it is not clever about your wishes. It only does what you write.

## Now the code
Here is the same idea as a tiny program. It stores the steps, then prints them one by one.

<CodeTabs
python={`def make_chai():
    steps = [
        "boil water",
        "add tea leaves",
        "add milk and sugar",
        "pour into cup",
    ]
    for step in steps:
        print(step)   # do this step exactly

make_chai()`}
javascript={`function makeChai() {
  const steps = [
    "boil water",
    "add tea leaves",
    "add milk and sugar",
    "pour into cup",
  ];
  for (const step of steps) {
    console.log(step); // do this step exactly
  }
}

makeChai();`}
java={`public class MakeChai {
    static void makeChai() {
        String[] steps = {
            "boil water",
            "add tea leaves",
            "add milk and sugar",
            "pour into cup"
        };
        for (String step : steps) {
            System.out.println(step); // do this step exactly
        }
    }

    public static void main(String[] args) {
        makeChai();
    }
}`}
cpp={`#include <iostream>
#include <string>
#include <vector>

void makeChai() {
    std::vector<std::string> steps = {
        "boil water",
        "add tea leaves",
        "add milk and sugar",
        "pour into cup"
    };
    for (const auto& step : steps) {
        std::cout << step << "\\n"; // do this step exactly
    }
}

int main() {
    makeChai();
}`}
csharp={`using System;

class MakeChai
{
    static void Make()
    {
        string[] steps = {
            "boil water",
            "add tea leaves",
            "add milk and sugar",
            "pour into cup"
        };
        foreach (string step in steps)
        {
            Console.WriteLine(step); // do this step exactly
        }
    }

    static void Main() => Make();
}`}
/>

Different languages look a bit different. The idea is the same: a list of clear steps, run in order.

## Common mistakes
- Writing vague steps like "make it tasty". The robot cannot taste.
- Getting the order wrong. Boil before you pour.
- Assuming the computer "knows what you meant". It only knows what you wrote.

## Interview angle
<InterviewTip>
Interviewers often start with: "Explain this like I am new."
Practice saying: "A program is a list of exact steps for a computer."
Then give a short real example — chai, a rickshaw route, or packing a school bag.
Clear talk beats fancy words.
</InterviewTip>
