## What you will learn
- Why loops exist: repeat without copy-paste.
- How a counter `i` walks from 1 to n.
- How to sum numbers from 1 to n with a loop.

## The story
<Analogy emoji="🍽️" title="Washing 10 plates">
After dinner there are 10 dirty plates.
You do not write "wash plate" ten separate times in a diary.
You think: while there is a dirty plate, wash one, then take the next.
That repeat-until-done idea is a **loop**.
The washing steps stay the same. Only the plate number changes.
</Analogy>

Programs use loops for the same reason. Repeat clear steps until a stop rule says you are finished.

    messages = []

def sum_to_n(n: int) -> int:
    total = 0
    i = 1
    while i <= n:
        total = total + i
        i = i + 1
    return total

print(wash_plates(3))

## Common mistakes
- Forgetting to increase `i`, so the loop never ends.
- Starting at 0 when you meant 1, or stopping before n.
- Using a condition that is already false, so the loop body never runs.

## Interview angle
<InterviewTip>
When you see "for each" or "repeat until", think loop.
Say the stop rule first: "i goes from 1 to n."
Then say what changes each time: "add i to total."
Interviewers like hearing the plan before the syntax.
</InterviewTip>
